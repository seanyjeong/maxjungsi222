# 2026년 9월 가채점 통합 코호트

## 사용자 계약

- 2027학년도 화면과 학생등록에 고2·고3을 함께 둔다.
- 고2를 등록하거나 성적을 저장할 때 2028학년도로 옮기지 않는다.
- 가채점 화면은 학생의 `grade`로 과목 체계를 자동 결정한다.
  - 고2: 국어, 수학, 영어, 통합사회, 통합과학
  - 고3: 기존 국어·수학 선택과목과 사회·과학탐구 선택과목
- 원점수 저장 시 이투스 2026년 9월 기준으로 표준점수·백분위·등급을 계산한다.
- 등급컷과 최고표점은 2026-09-04 18:34 KST에 고3 22과목·고2 4과목 이투스 공식 페이지와 전수 대조한 스냅샷을 사용한다.
- 성적분포는 2027학년도에 등록된 고2·고3 성적을 함께 집계한다.

## 데이터 계약

- 학생기본정보와 학생수능성적의 학년도는 모두 `2027`을 사용한다.
- 고2 원자료는 이투스의 고2 페이지를 출처로 유지한다.
- 고2 4과목 등급컷과 최고표점은 `2027` 조회 키에도 복제한다.
- 기존 `2028` 기준표는 이전 화면과 관리 도구의 호환을 위해 유지한다.
- 기존 `통합국어`, `통합수학` 값은 각각 `국어`, `수학`으로 정규화한다.

## 운영 검증

- 기준표 적용 전 `정시예상등급컷`, `정시최고표점` 대상 행을 별도 테이블에 백업한다.
- 고2 성적 교정 전 일산·2학년·2027·9월·가채점 행만 별도 백업한다.
- 과목 정규화와 변환값 완전성을 트랜잭션 안에서 확인한 뒤 커밋한다.
- 브라우저는 학생 목록·저장·재계산을 모두 2027 한 번만 요청해야 한다.
