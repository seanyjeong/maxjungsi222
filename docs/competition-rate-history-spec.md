# 정시 전년도 경쟁률 Spec

## Problem

정시 학교 정보 화면에서 2026·2027학년도에 각각 2025·2026 경쟁률을
일관되게 보여주고, 제공된 엑셀 이력을 검증 가능한 형태로 보존해야 한다.

## Scope

- 개인상담, 대학정보, 계산기, 컨설팅 허브, 맥스라이브, 학교별 상담 등
  학교 정보를 표시하는 화면에 전년도 경쟁률을 노출한다.
- 엑셀에 없는 값이나 다른 군·학과로의 자동 유사도 매핑은 만들지 않는다.

## Acceptance Criteria

1. 2027학년도는 2026 경쟁률, 2026학년도는 2025 경쟁률만 표시한다.
2. 동일 모집단위의 복수 계산 U_ID에는 같은 원본과 범위 설명을 적용한다.
3. 데이터가 없거나 매핑이 모호하면 `전년도 경쟁률 자료 없음`으로 표시한다.
4. 기존 `/jungsi/schools`, `/jungsi/formula-details` 응답과 계산 결과를 유지한다.
5. 기술 오류는 상태 코드·CORS·stack 없이 한국어로 안내한다.

## Data Contract

- `정시기본.tags`에는 `type`, `catalogYear`, `year`, `rate`,
  `quota`, `applicants`, `scope`를 가진 파생 태그만 추가한다.
- `catalogYear = year + 1`이 아니거나 화면 학년과 다르면 표시하지 않는다.
- 기존 태그는 보존하며 알 수 없는 태그는 계속 안전하게 무시한다.

## Migration And Rollback

- 원본 이력과 source hash를 보존하고, 변경 전 `정시기본.tags`를 백업한다.
- 롤백은 백업 tags를 복원한 뒤 이번 source hash의 이력 행을 제거한다.
