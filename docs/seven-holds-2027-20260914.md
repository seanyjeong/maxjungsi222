# 2027학년도 7개 대학 수능·실기 재검수

2026-09-14 용인·원광·세종·조선·호서·안양·계명 7개 대학, 9개 모집단위의 공식 요강을 재검토했다. 확인한 계산 정정과 임시 적용 안내를 운영에 반영했으며, 개인상담·통합계산기·대학정보에서 동일하게 확인할 수 있다.

## 계산과 화면 변경

- 세종 체육학과: 국어·영어 반영비율을70:30에서50:50으로 정정했다. 수능500점의 산식은 `(국어 표준점수 + 영어200점 환산점수) × 1.25`다. 한국사는 필수응시이며 가산점은 없다. [공식 요강](https://ipsi.sejong.ac.kr/ipsi/regular/notice.do?mode=view&articleNo=2779) 본요강 물리47쪽에 따른다.
- 계명 스포츠마케팅: 원천400점 계산을 최종100점 척도로 정리하고, 기존2027 수능컷·총점컷12행도 같은 비율로 환산했다. 개인상담·통합계산기·PDF 카드에서 소수4자리까지 표시한다. 과거 상담 점수는 화면 복원 시 원래 성적으로 재계산한다.
- 다른5개 대학의 수능은 공식 산식과 일치하여 기존 계산을 유지했다. 대학별 중복 경계·누락 배점·파울 규정의 미확정 부분은 안내에 표시했다.

계명 요강은 최종100점과 한국사400점/300점 기준을 함께 명시한다. 적용 산식은 `(국어백분위 + 수학백분위 + 영어환산 + 탐구2과목평균 + 한국사400점기준가산) / 4`이며, 가산점으로 만점을 넘으면 초과값을 허용한다. 한국사 비례환산은 원문을 종합한 **임시 해석**이다. 가산점의 최종 환산 단계에 대한 공식 상세 예시 확인이 남으며, 대학정보와 계산로그에도 이를 표시한다. [계명 공식 입학안내](https://www.gokmu.ac.kr/guide/board.htm?bbsid=notice&mode=view&bltn_seq=85544&etc1=common).

## 검증

- 실제 Claude와 공식 원문·합성 성적만으로 독립 계산하고 원본 페이지에서 차이를 재판정했다.
- 수능45사례와 실기29사례를 운영 API와 대조했다. 계명 수능5사례 및 원문 경계가 미확정인 실기7사례는 임시 해석의 계산 일치 검증이다.
- 백엔드38개 테스트, 기존389개 학교·학년도에 대한5,835개 계산과1,167쌍 라우트 회귀 비교를 통과했다.
- 적용·복구와 동시변경 차단 시험, 관련 프론트 단위·브라우저 검증을 통과했다. 합성학생만 사용했으며 실제 학생·상담 정보를 시험 저장하지 않았다.
- 계명 계산85.6250점과 MAX 컷66.25점, 이전척도 캐시의 재계산, PDF4자리 표시를 확인했다.

현재 공식 후속 확인 대상은 [남은 목록](admissions-2027-pending.md)을 참조한다. 계산 정정·상담용 임시 적용과 대학의 공식 확정은 구분한다.
