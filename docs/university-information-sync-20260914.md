# 대학정보 최신 반영 상태 동기화

2026-09-14 기준으로 대학정보 목록과 상세 화면에 같은 학과별 반영 기록을 표시한다. 목록에는 반영 상태를 요약하며, 상세에는 확인한 전형·수능·실기 기준과 남은 작업, 근거를 제공한다. 부분계산이나 발표 대기 항목을 전체 검수 완료로 표시하지 않는다. 2026 화면에는 2027 안내를 적용하지 않는다.

서울대 체육교육과의 1단계 선발은 [2026 공식 모집요강 30쪽](https://admission.snu.ac.kr/webdata/admission/files/2026jungsi.pdf#page=34)과 [2027 공식 모집요강 31쪽](https://admission.snu.ac.kr/webdata/admission/files/2027jungsi.pdf#page=35) 모두 **3배수**다. 목록에는 ‘전년과 동일’, 상세에는 ‘2026학년도 3배수 → 2027학년도 3배수 (전년과 동일)’와 양 학년도 원문 링크를 표시한다. 공식 근거와 다른 ‘작년 4배수에서 3배수로 변경’ 표기는 추가하지 않는다.

앞서 정리한 [탐구변환표 전체 후속 목록](admissions-2027-later-updates.md)의 16개 대학·32개 모집단위를 대학정보 상세에도 연결한다. 현재 표를 사용하는 27개 모집단위는 기존표 유지·발표 후 갱신을 안내한다. 고려세종81·부산174의 표준점수 적용과 한국외대165·166·167의 백분위 적용은 요강과 다른 현 상태를 설명하고 별도 확인이 필요하다고 표시한다. 연세23은 기존표 출처·연도 확인을 함께 안내한다. 이 작업으로 변환표 값이나 계산 설정을 바꾸지 않는다.

호서70·204는 메디신볼 최저 구간 정상 기록30점·최종파울0점과 달리기0.01초 급간의 적용 상태를 상세 안내에 명시한다. 이미 적용한 안양2회 파울0점과 용인·원광·세종·조선의 최신 반영 기록도 목록 및 상세에서 확인한다.
