# 2027학년도 최신화 확인·후속 업무

현재 자료나 산식을 확인할 항목, 발표·시험 이후 진행할 항목, 이미 적용한 상담 기준을 구분한다. 성격이 다른 항목을 합쳐 전체 보류 대학 수로 집계하지 않는다. 탐구변환표의 미발표는 해당 표를 사용하는 대학 전체의 정기 갱신 업무로 관리한다.

## 2. 발표 후·시험 후 진행할 후속 업무

| 대상 | 현재 적용 | 후속 시점과 작업 |
|---|---|---|
| 대학별 탐구변환표 전체 | 현재 사용하는 기존 상담표 유지 | 2027학년도 공식표 발표 후 갱신·수기 재검산. [16개 대학·32개 모집단위 전체 목록과 적용 상태](admissions-2027-later-updates.md)에서 관리한다. |
| 서울대 체육교육 96 | **1단계 수능 100%·3배수**로 계산·안내 | 시험 및 1단계 결과 이후 합격자 최고·최저점을 확보해 2단계 환산을 확인한다. 실기 실시방식 등 상세 안내는 2026년 10월 12일 이후 확인한다. |
| 인천대 스포츠과학 27·스포츠의학 28·체육교육 29 | 기존 상담용 실기표 임시 적용 | 2027 정시 상세 실기표가 발표되면 갱신한다. |
| 한국해양대 해양스포츠과학 176 | 기존 상담용 실기표 임시 적용 | 2026년 12월 예정된 상세 체육실기요강 발표 후 갱신한다. |

서울대 요강은 1단계를 “100% (3배수)”로 명시한다. 2단계에 필요한 합격자 최고·최저점과 실기 상세 안내는 이후 확보할 자료이며, 현재 1단계 수능 계산을 보류하는 사유로 두지 않는다. [서울대 정시요강 인쇄 31~32쪽](https://admission.snu.ac.kr/webdata/admission/files/2027jungsi.pdf)

실기 발표 확인: [인천대 체육학부 입학안내](https://sports.inu.ac.kr/bbs/board.php?bo_table=sub1_3&wr_id=12), [한국해양대 정시 공지](https://www.kmou.ac.kr/ipsi/na/ntt/selectNttInfo.do?nttSn=10378433&mi=3326).

아래 항목은 상담 기준을 적용한 상태다. 원문 중복·미기재 부분은 대학의 확정 배점으로 표시하지 않고, 공식 정정이 나오면 다시 대조한다.

|---|---|---|
| 용인대 | 특수체육교육 111 | 남자 제자리멀리뛰기 중복 표기는 261cm 이상 269cm 미만 54점,269cm 이상 61점으로 해석한다. |
| 원광대 | 체육교육 25 | 배구 중복 경계인 남 26회·여 24회는 87점을 적용한다. |
| 세종대 | 체육 102 | 공식 HWP로 45~25점을 포함한 전체 96급간을 확인했다. 메디신볼 남 9m·여 7m 미만만 원문 미기재 구간으로 상담 25점을 적용한다. |

| 안양대 | 스포츠과학 155 | **2회 파울은 해당 종목 0점**으로 적용한다. 원문의 수치 없는 ‘기본점수’를 별도 상담 기준으로 정리했으므로 현재 보류에서 제외한다. |

앞선 5개 대학의 세부 내용은 [최신 원문·상담 기준 반영](five-practical-2027-20260914.md)을 참고한다. 안양의 0점은 사용자 확인에 따른 상담 기준이며, 대학이 미기재 수치를 공식 확정했다는 뜻은 아니다. [안양대 공식 요강](https://enter.anyang.ac.kr/10000018?detail=126)

이화·건국 서울·명지의 실기 상대평가는 상세 실기표 작업 대기에서 제외한다. 서경은 사용자 지시에 따라 이번 작업에서 제외하며, 수시이월 최종 인원과 주관평가 점수 제외 항목도 위 확인 목록에 중복 합산하지 않는다.
