# 2027학년도 최신화 완료·발표 후 갱신

**2026년 9월 15일 사용자 운영 기준과 계명대 원문 재검수를 반영해 현재 계산 기준 확인 보류는 0건이다.** 새로 발표될 탐구변환표·상세 실기표는 발표 후 갱신할 자료로 관리한다.

계명대의1.25점은 원문의400점당5점을100점으로 단위환산한 결과다. 원문에 없는 대학 공식 계산 예시를 만들었다는 뜻은 아니다. 예: 국어80·수학70·영어3등급94·탐구90/70 평균80·한국사1등급이면 `(80+70+94+80+5)/4 = 82.2500`점이다.300점당3.75점도 같은 비율이므로 최종100점당1.25점과 일치한다. [계명대 공식 정시요강29쪽](https://www.gokmu.ac.kr/guide/board.htm?bbsid=notice&mode=view&bltn_seq=85544&etc1=common)

이화는 탐구 두 변환점수 합을 두 최고점 합으로 나누던2027 계산을 전년도 개별 비율 평균으로 맞췄다. 국어·수학 분모는 영역 최고점이며 등록값이 없으면 전체 선택과목 최고점의 최댓값을 사용한다. 부산 파울20점은 사용자 지정 상담 기준이다. [이번 정리 및 검증](admissions-policy-closeout-20260915.md)

앞선 5개 대학의 세부 내용은 [최신 원문·상담 기준 반영](five-practical-2027-20260914.md)을 참고한다. 안양의 0점은 사용자 확인에 따른 상담 기준이며, 대학이 미기재 수치를 공식 확정했다는 뜻은 아니다. [안양대 공식 요강](https://enter.anyang.ac.kr/10000018?detail=126)

이화·건국 서울·명지의 실기 상대평가는 상세 실기표 작업 대기에서 제외한다. 서경은 사용자 지시에 따라 이번 작업에서 제외하며, 수시이월 최종 인원과 주관평가 점수 제외 항목도 위 확인 목록에 중복 합산하지 않는다.
