# 2027학년도 최신화 확인·후속 업무

현재 자료나 산식을 확인할 항목, 발표·시험 이후 진행할 항목, 이미 적용한 상담 기준을 구분한다. 성격이 다른 항목을 합쳐 전체 보류 대학 수로 집계하지 않는다. 탐구변환표의 미발표는 해당 표를 사용하는 대학 전체의 정기 갱신 업무로 관리한다.

이번 원문 재확인 기준일은 **2026년 9월 15일**이다. 현재 별도 산식 확인 대상은 계명195와 이화114 두 건이며, 상세 실기표와 연례 탐구변환표는 발표 후 후속 업무로 관리한다.
