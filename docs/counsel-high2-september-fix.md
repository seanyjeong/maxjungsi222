# 고2의 2027학년도 상담 활성화

2027학년도에 등록된 고2도 개인상담과 통합계산기에서 선택한 시험 성적으로 상담한다.
학생 목록 요청에 `cohort=registered`를 지정하여 등록 학년도의 모든 학년을 포함한다.
시험을 지정했을 때 사용되던 가채점용 자동 분류가 고2를 제외하던 문제를 해결한다.

- 대상: 개인상담, 통합계산기. 변경된 스크립트에 캐시 버전을 갱신한다.
- 성적 조회·수능 환산·상담 저장은 선택한 2027학년도와 모형을 유지한다.
- 고2 국어·수학·통합사회·통합과학 성적을 원래 과목명으로 전달한다.
- 이는 2027 모형을 이용한 상담이며 2028학년도 전형 계산 엔진 도입은 아니다.
- 기존 등록 학년도, 성적 데이터, 서버 API 및 계산 공식은 변경하지 않는다.
- 성적 미입력 학생도 목록에 보이며 해당 모형 성적이 없다는 기존 안내를 사용한다.

검증: `tests/test_counsel_student_cohort_playwright.py`는 고2·고3·미입력 학생 표시,
9월→6월 성적 전환, 두 계산 화면의 고2 포함, 2027 계산·저장 요청을 확인한다.
기존 9월 성적·개인상담·최고표점 회귀 검사를 함께 실행한다.
운영 학생 조회는 읽기만 수행하고 상담 저장 검증은 가상 학생과 차단된 요청으로 수행한다.

배포: 운영 main 기준으로 두 조회 옵션과 두 캐시 버전, 테스트, 본 문서만 적용한다.
