# 2027학년도 탐구변환표 발표 후 갱신 목록

대학별 탐구변환표는 **해당 표를 사용하는 모든 대학의 정기 갱신 업무**로 관리한다. 발표 전에는 현재 사용하는 기존 상담표를 유지하고, 2027학년도 공식표가 나오면 전행 대조와 수기 재검산을 거쳐 갱신한다. 표가 아직 발표되지 않았다는 이유만으로 특정 대학을 현재 최신화 보류 학교로 분류하지 않는다.

대상은 **16개 대학·32개 모집단위**이며, 이번 반영으로32개 모집단위 모두 대학별 탐구변환표를 사용한다. 앞서 누락됐던 고려 세종81·한국외대165~167·부산174의 적용을 정정한다. 부산은 공식2026 정정표의 소수4자리 정밀도를 보존해 계산한다. 이 목록은 탐구표 사용과 발표 후 갱신 범위를 정리한 것이며, 모든 대학의 수능 산식 검수가 끝났다는 뜻은 아니다. 이번 관련 원문 재확인 기준일은 **2026년9월15일**이다.

## 전체 대상

## 기존표의 연도와 검수 상태

**저장학년도가2026이라는 사실만으로 해당 대학의2026 공식 원표임을 확정하지 않는다.** 기존표의 공식 원표 대조 기록을 확인한 대상은 성균관19·연세22이며, 이번에는 부산174의 공식2026 정정표를 추가로 확보했다. 나머지 기존표는 원표 출처·연도 미확인 상태를 유지하며 새 표 갱신 때 함께 대조한다. [성균관2026 성적 반영 안내](https://admission.skku.edu/common/download.php?fpath=board/202512230903523VL98J.pdf), [연세2026 상세 산출방법·통합변환표](https://www2.yonsei.ac.kr/entrance/2026/jungsi/docu/2026ksat.pdf), [부산2026 정정표](https://go.pusan.ac.kr/college_2016/pages/index.asp?p=50&b=B_1_1&bn=49039&m=read)

연세 체육교육23의 기존표는 스포츠응용산업22의 검수된 표와 값이 다르다. 현재 값을 유지하며 새 표 갱신 때 출처·연도·적용 유형도 함께 확인한다. 고려81은 세종캠퍼스 기존 상담표를 적용하되 원표 연도를 단정하지 않는다. 부산174는 소수4자리 정정값이 두 자리로 줄어들지 않도록 정밀도를 보존한다.

성균관19·연세22·건국71은 기존 수능 산식 검수 기록이 있다. 고려81·한국외대165~167·부산174는 이번 탐구 적용 및 산식 정정 범위에 포함한다. 이화114의 혼합·과탐 최고점 분모는2027 공식 상세 확인이 남아 있어 별도 관리한다. 다른 학교의 실기표 검수나 탐구표 사용 여부 확인을 수능 산식 전체 검수 완료로 확대하지 않는다. [현재 자료·산식 확인 목록](admissions-2027-pending.md)

## 발표 후 갱신 순서

1. **2027학년도** 대학별 공식 변환표와 정오표를 확보하고 캠퍼스·전형·모집단위를 확인한다.
2. 사탐·과탐의 백분위별 점수, 최고점, 가산점, 반영 과목 수를 기존표와 대조한다. 성균관은 영어 환산표도 함께 확인한다.
3. 혼합 탐구, 상위과목·영역 선택, 최고점, 소수 처리 경계를 포함해 원문 산식으로 수기 재검산한다.
4. 검토된 표와 안내를 갱신한다. 부산은 표의 소수4자리 값을 저장·계산 양쪽에서 보존하는지 함께 확인한다. 별도 산식 확인이 필요한 학교는 해당 근거도 확보한다.

고려 세종 요강은 변환표를 “대학수학능력시험 성적 발표 이후” 공지한다고 안내한다. 한양 ERICA는 2026년 12월 18일 이후 공지 예정으로 안내한다. 대학별 공지 시점을 확인해 순차 갱신하며, 특정 4개 대학만의 보류 문제로 집계하지 않는다.
