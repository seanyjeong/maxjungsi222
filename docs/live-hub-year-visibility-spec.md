# 정시 라이브·컨설팅 허브 개인정보·학년도·가독성 Spec

## Problem

Windows에서 작은 보조 문구의 대비가 부족하다. 라이브와 컨설팅 허브에서 2026·2027 지원자의 이름·지점·학교를 필요할 때만 안전하게 가려야 한다.

## Scope

### In

- Windows 기본 렌더링을 유지하고 보조 텍스트 대비를 높인다.
- 라이브와 컨설팅 허브가 2026·2027 선택지를 제공한다.
- 학년도 변경 시 해당 연도의 학교·지원자 API를 다시 호출한다.
- 두 화면에 개인정보 가리기 버튼과 원장 비밀번호 재확인 모달을 제공한다.
- 가림 상태에서 이름은 가운데를 `○`, 지점은 `○○`, 학교는 접미사를 제외한 가운데 한 글자를 `X`로 표시한다.

### Out

- 정시 DB 데이터 추가·수정
- 프로덕션 백엔드 재시작
- 2025 선택지 제거

## Acceptance Criteria

- 두 페이지 모두 2026·2027 학년도 선택지를 노출한다.
- 라이브는 `/jungsi/university-final-applicants/{U_ID}/{year}`, 허브는 `/jungsi/university-applicants/{U_ID}/{year}`를 선택 연도로 호출한다.
- 개인정보 모드 전환은 현재 JWT의 원장 아이디와 비밀번호를 `/susi/login`으로 재확인한 뒤에만 성공한다.
- 가림 상태에서는 두 화면의 렌더링 DOM 어디에도 원문 이름·지점·학교가 남지 않으며 우리 지점 강조도 숨긴다.
- 가림 상태는 같은 탭의 2026·2027 조회와 두 화면 이동에서 유지된다.
- 공통 보조 텍스트 색상은 밝은·어두운 테마 모두 일반 텍스트 기준 AA 대비를 충족한다.
- 정적 계약 테스트와 브라우저 렌더 검증이 통과한다.

## Test Plan

- 두 페이지의 연도 선택·API 경로 정적 계약 테스트
- 마스킹 순수 함수·재인증 단위 테스트
- 두 페이지의 비밀번호 실패/성공/해제와 2026·2027 유지 Playwright 테스트
- 색상 토큰과 Windows 렌더링 규칙 계약 테스트
- 2026·2027 각각의 브라우저 네트워크 스모크
