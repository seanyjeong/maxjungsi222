# 2027학년도 대학정보

대학정보는 개인상담·통합계산기와 같은 운영 자료를 읽는다. 학과명, 모집군, 모집인원, 반영비율과 실기 배점은 선택한 학년도를 기준으로 표시한다.

- 최근 검수한 38개 모집단위에는 반영 내용, 공식 출처와 확인할 사항을 제공한다. 모든 2027학년도 자료의 검수가 끝났다는 의미는 아니다.
- 수원대 스포츠과학부 모집인원은 2027 정시 요강 31쪽에 따라 기초체력 20명·전공실기 40명으로 정정했다. 학부 전체 인원 60명을 각 모집구분에 중복 표시하던 오류를 수정했다.
- 수원 전공실기는 기초실기 300점만, 숙명 체육교육과는 높이뛰기 75점만 계산한다. 주관평가 배점과 선택 종목을 별도로 안내하며 최종총점은 산출하지 않는다.
- 영어·한국사 등급표와 종목별 전체 등록 배점을 펼쳐 볼 수 있다. 종목별 원점수와 최종 실기 환산점수는 단위가 다를 수 있다.
- 임시 적용 중인 배점표와 계명대의 환산 단위 확인 사항은 확정 자료와 구분해 안내한다.
- 과거 컷은 해당 학년도를 표시하며, 현재 반영비율·총점이 다른 경우 직접 비교하지 않는다.
- 학년도 변경 중 늦게 도착한 이전 자료는 화면에 덮어쓰지 않는다. 조회 실패 시 다시 불러올 수 있다.

검증: 단위 테스트 14개, 브라우저 회귀 6개, 실제 운영 API와 38개 학과 상세정보 대조. 덕성 실기 원점수 100×6=600점, 안양 200×0.3=60점도 실제 계산 API와 대조했다.
