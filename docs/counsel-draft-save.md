# 개인상담 입력 중 저장

실기 기록이 비어 있거나 일부만 입력되면 해당 대학의 실기 계산은 대기한다.
이 상태가 다른 대학·메모의 저장까지 막지 않도록 상담 목록 전체를 저장한다.
입력한 실기 기록과 메모는 보존하고, 계산 전 실기 반영점수와 총점은 `null`로 보낸다.
계산 성공 후 확정 점수로 다시 자동 저장한다. 계산 오류도 기록 저장을 막지 않는다.

저장 성공은 `저장됨`으로 표시하며, 계산을 마치지 않은 대학이 있으면
`실기 계산 대기`를 덧붙인다. 저장 후 복원할 때 기록을 다시 계산한다.

검증: Playwright로 일부 입력·전체 입력·빈 기록·계산 오류·여러 대학 동시 저장·복원·
기록 전체 삭제 후 메모 보존을 확인한다. 합성 학생을 사용하고 저장 API를 가로채므로
검증 과정에서 실제 학생 상담 데이터는 변경하지 않는다.

운영 저장 API의 실기 점수·총점 컬럼은 nullable이며 기존 계약을 유지한다.
DB 스키마나 점수 계산식 변경은 없다.
