# 안양대·서울대 2027학년도 반영

기준일: 2026-09-14. 대상은 안양대 스포츠과학과(155)와 서울대 체육교육과(96)다.

## 안양대

2회 파울 확정 종목은 사용자 지정 상담 기준으로 0점 처리한다. 모집요강의 ‘기본점수’에 숫자가 명시되어 있지 않아, 이 0점을 학교가 공표한 공식 배점으로 설명하지 않는다.

- 입력: `2회파울`, `2회 파울`, `2F`. 일반적인 `F`나 `파울`만으로 두 번의 파울을 추정하지 않는다.
- 제자리멀리뛰기·배근력은 각각 100점 만점이며, 합계에 `60 / 200`을 곱한다.
- 한 종목 2회 파울 + 다른 종목 만점 = 실기 30점. 두 종목 모두 2회 파울 = 0점.
- 정상 기록 배점표는 유지하며 누락·음수·미응시를 0점 기록으로 바꾸지 않는다.
- 수능은 국어 백분위와 영어 등급 환산점수의 평균 × 0.4를 유지한다. 한국사는 필수 응시다.

## 서울대

상담·계산기·대학정보·상담 PDF의 기준은 **1단계 수능 점수**다. 1단계는 수능 100%로 모집인원의 3배수를 선발하며 동점자는 모두 선발한다. 계산기 순위는 이 수능 점수로 정한다. 앱의 지점 내 순위가 대학 지원자 전체의 합격 순위를 의미하지는 않는다.

`국어 표준점수 + 수학 표준점수 × 1.2 + 탐구 2과목 표준점수 합 × 0.8 − 영어 감점 − 한국사 감점`

영어 1~9등급 감점은 0 / 0.5 / 2 / 4 / 6 / 8 / 10 / 12 / 14점, 한국사는 0 / 0 / 0 / 0.4 / 0.8 / 1.2 / 1.6 / 2 / 2.4점이다. 사회·과학탐구 혼합을 허용하며 수학 선택과목 또는 과탐Ⅱ 가산점은 없다. 제2외국어·한문은 반영하지 않는다.

수기 사례: 국어130·수학140·탐구55/53·영어1·한국사1이면 `130 + 168 + 86.4 = 384.4`. 이 점수를 100점이나 1,000점으로 재환산하거나 상한 처리하지 않는다. 독립 수기 사례 8건에서 영어·한국사 감점, 탐구 조합, 400점 초과 결과를 확인했다.

기존 2단계 정보의 잘못된 1,000점·실기200점 메타데이터는 요강의 100점·실기20점으로 수정했다. 1단계 화면에는 실기 입력, 최종총점, 단위가 검증되지 않은 기존 총점컷을 표시하지 않는다. 저장되어 있던 실기 기록과 점수·최종총점은 보존하며, 1단계 점수와 메모를 저장해도 해당 값을 지우지 않는다.

2단계 수능 환산은 시험 후 최고·최저점이 확보될 때 적용한다. 실기 세부 요강은 10월 12일 이후 다시 확인한다. 현재 공개된 종목별 원점수 합계100점과 전형 실기20점만으로 세부 배점표나 환산법을 추정하지 않는다. 예전 실기표 116행은 보존하되 1단계 화면에서 사용하지 않는다.

출처: [서울대 2027학년도 정시 모집안내](https://admission.snu.ac.kr/webdata/admission/files/2027jungsi.pdf), 인쇄31쪽의 1·2단계 전형 방법 및 감점표, 75~76쪽의 수능 반영 규칙. 디지털 원문·좌표·해당 페이지 이미지를 대조하고 Claude의 독립 판독과 수기 계산 결과를 교차 확인했다.

## 탐구 변환표 후속 작업

탐구 변환표는 네 학교에 한정된 보류 항목이 아니다. 현재 사용 중인 전년도 이월 값을 유지하고 대상 전체를 연간 갱신 목록으로 관리한다. 대학별 2027 변환표가 발표되면 출처·탐구 과목·백분위 전 구간·만점과 분모를 함께 검증한다. 목록과 현재 산식·설정 확인 사항은 [후속 갱신 목록](admissions-2027-later-updates.md)과 [현재 확인 목록](admissions-2027-pending.md)에 기록한다.
