# 2027 정시 보류 항목 원문 재검수

2026년 9월 15일 기준 공식 정시 모집요강·정정 공지·학과 실기 안내를 다시 대조했다. 외대 3개 전형, 고려대 세종 자유전공, 부경대 해양스포츠, 부산대 스포츠과학의 계산·모집정보를 수정하고 대학정보 목록과 상세에 같은 상태를 표시한다.

## 이번 반영

| 대상 | 반영 내용 |
|---|---|
| 한국외대 글로벌스포츠산업 일반165 | 국어30·수학35·영어15·탐구20. 영어 150점 환산표와 한국사 감점표를 정정한다. |
| 한국외대 농어촌166·기초생활/차상위167 | 국어30·수학30·영어20·탐구20. 영어는 200점 환산표를 사용한다. |
| 고려대 세종 자유전공(문화스포츠)81 | 나군8명. 국어35·수학20·영어20·탐구25의 개인 가중합을 최고점 가중합으로 나누어1000점 환산. 한국사는 필수응시이며 가산하지 않는다. |
| 부경대173 | 스마트헬스케어학부(해양스포츠전공)에서 **해양스포츠학과**로 명칭 변경, 가군22명. 수능은 국어표점×245/200 + 영어환산×245/200 + 탐구2표점합×210/200 + 한국사다. |
| 부산대 스포츠과학174 | 가군10명,1단계3배수. 수능은 국어표점×300/200 + 영어환산 + 탐구2변환합×300/200 + 한국사다. 수학은 미반영한다. |

외대는 국어·수학의 영역 최고표점, 탐구의 대학별 변환표 최고점으로 나눈 비율과 각 가중점수 단계에서 소수6자리까지 절사한다. 부경은 최종 결과만 소수4자리까지 절사하고, 부산은 중간·최종 점수를 소수4자리까지 절사한다. 고려대 세종은 원문에 별도 소수 처리 규정이 없어 기존 상담 화면의2자리 표시를 유지한다.

외대·고려 세종의 국어·수학 분모는 선택과목 개인별 최고점이 아닌 **영역별 최고점**이다. 선택한 시험의 영역 최고점 등록값을 우선 사용하며, 영역 키가 없는 모형은 국어2개·수학3개 선택과목 최고점이 모두 있을 때 그 최댓값으로 영역 최고점을 구한다. 필요한 자료가 없거나 성적이 공백·중복·미응시이면 계산을 보류한다. 이번 작업에서 모형별 최고표점 원자료를 새 공식 수능 자료로 확정하지 않는다.

부산 실기는 남녀4종목의128급간과 경계를 원문으로 대조했다. 각 종목20~50점의 합계80~200점에 기본80점을 다시 더하지 않는다. 한 종목 결시·중도 포기는 불합격이며 기록 누락은 계산 보류다. 추가 사용자 지시에 따라 종목별 파울·실격은 해당 종목 최저20점의 상담 기준을 적용한다.

## 탐구표와 저장 정밀도

외대는 기존 상담표를 유지한다. 고려81은 같은 세종캠퍼스3·4·5의 서로 동일한202행을 연결하며, 공식 원표 연도는 미확인으로 표시한다. 부산은 공식2026 정정표101값을 소수4자리 그대로 임시 적용한다. 기존 탐구표 저장 칸의2자리 제한 때문에 부산 표는 검수된 계산 설정에서 정확한 값을 사용한다.2027 표 발표 후 표 저장 정밀도와 교체를 함께 확인한다.

상담·최종지원의 수능점수와 총점은 소수6자리까지 저장할 수 있도록 확장한다. 기존 학생 점수와 수정시각을 보존하며 과거 값을 임의로 재계산하지 않는다. 최종지원은 화면에서 반올림한 숫자를 다시 읽지 않고 계산 상태의 정확한 값으로 저장한다. 개인상담·계산기·PDF·허브·맥스라이브·대학별 상담은 해당 학년도·학교의 표시 정밀도를 사용한다.

저장 정밀도 확장은 이전 계산 코드와 호환된다. 계산 코드 복구 시에도 이미 저장한 소수값을 버리는 역축소는 하지 않는다.

## 검증과 남은 항목

공식 원문에서 먼저 수기 기대값을 동결하고 계산 코드·실제 API 경로와 비교했다. Claude 페인에서 외대·고려 세종, 계명·부경, 부산의 원문과 산수를 독립 대조했다. 이미지 자료는 실제 Mistral OCR과 GPT 원본 판독을 함께 실행했으며, 표 병합·좌표·기호 오류는 원본으로 별도 판정했다. 자동 추출 승인 게이트에 남은 오류를 승인 완료로 바꾸거나 추출값을 DB에 자동 입력하지 않았다.

이후 사용자 지시와 계명 원문 재검수로 현재 산식 확인 보류를 해제했다. 계명은400점 한국사 배점을100점으로 단위환산하고, 이화는 전년도 개별 탐구 비율 평균 방식을 적용한다. 부산 파울·실격은 종목 최저20점, 서울은1단계만 제공하며2단계 환산을 후속 업무에서 제외한다. 부경·인천·한국해양의 상세 실기표와 탐구변환표는 발표 후 교체한다. [후속 정리](admissions-policy-closeout-20260915.md)

탐구표는 일부 대학에 한정하지 않고 **16개 대학32개 모집단위 전체**를 발표 후 갱신 목록으로 관리한다. [현재 확인 목록](admissions-2027-pending.md)과 [탐구표 전체 후속 목록](admissions-2027-later-updates.md)을 함께 갱신했다.

배포 전 검증:

- 수능·실기·과거 및 비대상 격리 테스트77개. 외대·고려 세종은4개 전형×4모형×6선택과목 조합96건을 영역 최고점 기준으로 따로 검산했다.
- 표시·저장 관련 Node23개 및 Chromium21개. Puppeteer로 대학정보71개 안내, 개인상담·계산기6개 전형과PDF, 저장·조회4개 화면의 실제 학교 산식 연결을 확인했다.
- 실제 MySQL 연결의 임시 테이블만 사용해 카탈로그 적용·복구와10종 충돌 차단을 검증했다. 학생 저장 정밀도는 실제 저장 핸들러와 임시 테이블을 연결해 소수4·6자리,0,NULL,정수부 경계를 확인했다.
- 운영 스크립트는 코드 복구·동시 변경 감지20개, 패키지 검증5개, 저장 정밀도 실패·서비스 복구15개를 검증했다. 정적 JS 프로젝트로 별도 lint·TypeScript 설정은 없으며 변경 JS 문법 검사와Git 공백 검사를 수행했다.
