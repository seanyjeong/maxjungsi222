# 2027 상대평가 대학 수능 환산 검수

2026-09-13 사용자 확인에 따라 이화여대 체육과학부, 건국대 서울 체육교육과, 명지대 스포츠학부의 실기는 상대평가로 분류한다. 등록 실기표는 상담용 추정 기준으로 유지하며 실기 상세표 작업 대기에서 제외한다. 인천대 3개 모집단위는 2027 정시 실기 상세표 발표 대기다.

## 수능 환산

- 이화: 국어·수학의 **영역별 최고표준점수**와 탐구 2과목의 변환점수 합으로 정규화하여 유리한 2영역을 300점씩 반영하고 영어 0~5점을 별도 가산한다. 선택과목명 공백 때문에 최고점을 찾지 못해 200으로 나누던 경로를 제거했다. 필요한 최고점이 없으면 점수를 만들지 않는다.
- 건국 서울: `(국어×0.45 + max(수학, 탐구변환점수 2과목 합)×0.30 + 영어환산×0.25)×600/200 + 한국사 감점`. 최종 소수점 넷째 자리에서 반올림하고 개인상담·통합계산기·PDF에 셋째 자리까지 표시한다.
- 명지: `국어 백분위×3 + 영어 환산×3 + 한국사 가산점`. 한국사 1~9등급은 `3.0, 2.8, 2.6, 2.4, 2.2, 2.0, 1.8, 1.6, 1.4`다. 수학·탐구는 반영하지 않는다.

이화·건국의 2027 탐구변환표는 수능 성적 발표 이후 갱신 대상이다. 현재 상담에 쓰는 기존 표를 올해 확정표로 표시하지 않는다. 이화는 탐구를 선택하지 않으면 국어·수학만으로 계산할 수 있고, 건국은 수학을 선택할 수도 있다.

## 직접 계산한 예제

| 학교 | 입력 및 독립 계산 | 결과 |
|---|---|---:|
| 명지 | 공식 예제: 국어 백분위90, 영어3등급96점, 한국사3등급2.6점 → `90×3+96×3+2.6` | 560.60 |
| 이화 | 국어131/영역최고144, 수학100/151, 탐구변환63.87·60.23/최고각70.33, 영어3 → `(131/144+124.10/140.66)×300+5` | 542.60 |
| 건국 서울 | 국어131, 수학100, 탐구변환63.97+60.35, 영어3등급194, 한국사3등급0 → `(131×.45+124.32×.30+194×.25)×3` | 434.238 |

명지 한국사 9개 등급, 이화 영역 선택·사탐/과탐 혼합·최고점 누락, 건국 수학/탐구 선택·한국사 감점을 검증한다. 이화·건국의 탐구 예제는 기존 상담용 변환표를 사용한 산식 검증이다.

기존 상담 저장 컬럼은 소수 2자리이므로 저장된 캐시 점수는 반올림된다. 개인상담 복원 시 원래 학생 성적으로 수능을 다시 계산해 건국의 셋째 자리를 복원한다. 과거 학생·상담·컷·지원 기록과 DB 컬럼 정의는 변경하지 않는다.

## 남은 목록의 기준

직접 확인할 실기 급간·파울 8개 모집단위와 계명대 수능 단위 1개가 남는다. 발표·자료 대기는 서울, 인천 3개, 부경, 한국해양, 연세, 성균관 및 이화·건국 탐구변환표로 총 10개 모집단위다. 합계 15개 대학·19개 모집단위이며, 명지대는 요청 범위를 완료했다. 상대평가 실기 3개를 실기표 대기 대상으로 다시 세지 않는다.
