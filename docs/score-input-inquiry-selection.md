# 성적표 입력 탐구 과목 선택

2026-09-29 변경.

- 탐구1에서 선택한 과목은 같은 학생의 탐구2 선택 목록에서 제외한다. 반대 방향도 동일하게 적용한다.
- 선택 과목을 변경하거나 비우면 이전 과목은 상대 목록에 다시 나타난다. 상대 탐구의 선택과 점수는 유지한다.
- 중복 선택 이벤트가 들어와도 기존 값을 삭제하지 않고 새 중복 선택을 거절한다.
- 이미 중복된 성적을 불러오면 값을 임의로 삭제하지 않고 ‘다시 선택’으로 표시한다. 두 과목이 중복된 상태의 변경분은 저장할 수 없다.
- 과거 버그로 이미 지워진 과목명을 점수만으로 추정해 복원하지 않는다.

검증: `node tests/score_input_official_rows.test.js`, `node tests/score_input_inquiry_browser.test.cjs`.
브라우저 검증은 Puppeteer를 사용하며 필요하면 `PUPPETEER_MODULE`에 설치된 모듈 경로를 지정한다.
학생 조회·저장 API는 합성 데이터로 대체하며 실제 학생 자료를 읽거나 변경하지 않는다.
