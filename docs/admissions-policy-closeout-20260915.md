# 2027 계산 기준 정리

2026년9월15일 사용자 지시에 따라 서울대2단계 환산을 작업 대상에서 제외하고, 이화의 전년도 수능 방식과 부산의 파울·실격 종목 최저점을 반영했다. 계명대는 원문을 다시 읽어400점 가산을100점 척도로 환산하는 기존 계산을 확인했다. 현재 계산 기준 확인 보류는0건이며, 미발표 표는 발표 후 교체할 자료로 관리한다.

## 계산과 표시

- 서울96: 1단계 수능100%·3배수만 제공한다. 상담·계산기·PDF·대학정보의 시험 후2단계 작업 안내를 제거했다.
- 계명195: 스포츠마케팅은 인문사회계열 방식의 국어·수학·영어·탐구평균 각25%다. 한국사 원천400점 기준5/4.5/4/3.5/3을 최종100점 기준1.25/1.125/1/0.875/0.75로 환산한다. 계산값은 유지하고 한국사 단위 확인 중 및 대학정보 총점 보류 표시를 해제했다.
- 이화114: 실제 등록2026 탐구식 `(탐구1변환/계열1최고 + 탐구2변환/계열2최고)/2`를 적용한다. 혼합 탐구의 비율과 상위2영역 선택을 전년도 방식으로 맞췄다. 국어·수학의 등록 영역 최고점이 없는3월·6월·수능 모형에서도 전체 선택과목 최고점이 있으면 영역 최고점을 구하도록 보완했다. 모든 선택과목 값이 없으면 계산을 보류한다. 대학정보와 학교 태그도 전년도 방식 적용 상태로 바꿨다.
- 부산174: 사용자 지정 상담 기준으로 F/G/파울/실격에 해당 종목 최저20점을 적용한다. 정상3종목 만점과 파울1종목이면170점,4종목 모두 파울이면80점이다. 정상 기록의 기존 급간, 기록 누락 보류와 결시·중도 포기 불합격 처리는 유지한다.
- 탐구표16대학32모집단위: 현재 표를 사용하고2027 공식표 발표 후 교체한다고 안내한다.

## 계명 원문 재확인

최신 공식PDF·HWP와 이미지의 계열 구분, 반영 비율, 한국사 표, 최종100점·가산점 별도를 함께 읽었다.400점당5점과300점당3.75점은 모두1.25%다. 따라서 최종100점에1.25점을 가산하는 것은 원문 척도에 따른 단위환산이다. 최종100점에5점을 그대로 더하면 원천400점에20점을 더한 비율이 되어 원문과 맞지 않는다.

국어80·수학70·영어3등급94·탐구90/70 평균80·한국사1등급의 예시는 `(80+70+94+80+5)/4 = 82.2500`이다. 이 수기는 원문에서 도출한 검산이며 대학이 제공한 공식 산출 예시라고 표시하지 않는다. 원본 이미지 직접 확인과 독립 검토, 실제 Claude 페인 교차 검산을 수행했다.

## 검증 범위

변경된 실제 수능·실기 API 경로를 로컬 고정 자료로 검증했다. 부산 남녀 정상 급간·파울·실격·결시·누락, 이화 혼합 탐구와4개 시험 모형의 영역 최고점, 계명 한국사5개 등급 묶음과100점 척도,2026 및 다른 학교 격리를 확인한다. 대학정보·개인상담·계산기의 브라우저 검증은 합성 학생만 사용하고 실제 학생 쓰기를 차단한다.

백엔드 엔드포인트와 학생 저장 스키마는 변경하지 않는다. 이화 학교 태그1행 외의 카탈로그와 기존 학생 점수는 쓰기 대상에 포함하지 않는다. 변경 코드와3개 화면은 이전 배포 파일의 해시 확인·백업 후 적용한다.
