# 충남대 기계체조 최종 점수 입력

2027학년도 충남대 체육교육과의 체조 자세 5개 입력란을 기계체조 한 칸으로 합친다.
학교에서 받은 최종 점수를 숫자로 입력하며, A/B/C 등급으로 재환산하지 않는다.
기계체조 45~100점은 소수점도 그대로 반영하고, 기존 핸드볼 45~100점과 합산한다.
예: 핸드볼 70점 + 기계체조 75.25점 = 실기 145.25점. 수능 300점과 합쳐 전형 만점은 500점.

배점표의 기계체조 45/100은 최저·최고 기준이다. 입력값을 두 급간으로 바꾸지 않는다.
상담 화면과 통합 계산기는 학교 점수 입력임을 안내하고, 계산 결과에도 입력 점수로 표시한다.
문자 등급이나 범위 밖 값으로 확정 점수를 만들지 않는다. 상담의 미완성 원기록은 임시 저장한다.

기존2026 및 기능 플래그가 없는 이전 공식 입력은 종전 엔진을 유지한다.
학교 점수 입력 플래그는 충남대2027에만 적용한다. 학생·상담 자료 일괄 수정은 하지 않는다.
공식 근거: 2027 충남대 요강28쪽 체조5개 평가항목 각각20/18/15/12/9점, 합계45~100점.
입력방식 통합은 학교가 합계 점수로 통보한다는 사용자 지시에 따른다.
